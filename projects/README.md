Use this directory for code that evolves across multiple challenges. Create each
project only when you need it. Possible names include `wallet-dashboard`,
`token-lab`, `anchor-lab`, `solana-agent`, and `capstone`.

Each project should document:

- What it does and which daily entries developed it.
- Prerequisites, dependency installation, and configuration.
- Commands to run it and any tests.
- The network and any public program IDs needed to reproduce the result.

Keep each project's native structure. For example, an Anchor project can have
its own `Anchor.toml`, `programs/`, and `tests/`; a browser app can have its own
`src/` and package manifest. Let the relevant scaffolding tool generate these
when you reach that challenge.

Extend the same project across related days and use Git history to show changes.
Link daily notes to the project and optionally record the day's commit hash so
you can revisit that version.
